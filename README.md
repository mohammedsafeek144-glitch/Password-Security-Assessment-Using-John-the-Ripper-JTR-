
# 🔐 Week 03 – Cybersecurity Internship

**Organization:** NETWORKWALKS  
**Internship Week:** Week 03

---

## 📌 Project Overview

I am happy to share that I successfully completed my Week 03 Cybersecurity Internship project with NETWORKWALKS.

As part of this week's practical training, I conducted a hands-on Password Security Assessment using John the Ripper (JTR).

The main objective was to understand password hash extraction, hash analysis, password auditing, and the importance of strong password security.

## 🎯 Project Objectives

- Understand password security fundamentals.
- Extract password hashes from protected PDF documents.
- Install and configure John the Ripper and Johnny.
- Perform password auditing in an authorized environment.
- Understand password recovery techniques.
- Verify recovered passwords by unlocking protected documents.
- Document the complete assessment process.

## 🛠️ Tools and Technologies

| Tool | Purpose |
|---|---|
| John the Ripper | Password auditing |
| Johnny | Graphical interface for JTR |
| Linux | Operating environment |
| PDF Hash Extraction Utility | Extracting PDF password hashes |
| Protected PDF | Assessment document |

## ⚙️ Activities Performed

1. Installed and configured Johnny.
2. Extracted a password hash from a protected PDF.
3. Created and prepared a hash file.
4. Loaded the hash file into Johnny.
5. Conducted a password security assessment.
6. Recovered the password in the authorized training exercise.
7. Verified the password by unlocking the PDF.
8. Documented the complete process.

# 💡 Key Learning Outcomes

One of the most valuable lessons from this exercise was understanding the relationship between passwords and password hashes.

I learned that weak and predictable passwords can be vulnerable to recovery attempts when password hash information becomes exposed.

This exercise highlighted the importance of:

1. Using long and unique passwords.
2. Avoiding common and predictable passwords.
3. Using password managers.
4. Protecting confidential documents.
5. Enabling multi-factor authentication.
6. Following secure credential management practices.

# 🔒 Ethical and Responsible Use

This project was conducted for educational purposes in an authorized training environment.

John the Ripper and other password auditing tools should only be used on files, systems, and accounts that you own or have explicit permission to assess.

Sensitive information, including passwords, hashes, private documents, and access tokens, should never be published in public repositories.
